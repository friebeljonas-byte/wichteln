# 🎁 Wichteln

Wichtel-Losung für eine Signal-Gruppe: ein Link für alle, jede/r sieht nur den eigenen Wichtel und
dessen Wunschzettel. Alle Daten werden im Browser Ende-zu-Ende-verschlüsselt und verschlüsselt in
Supabase gespeichert.

- `index.html`: die komplette App (eine Datei, kein Build nötig)
- `supabase.sql`: Datenbank-Schema, einmal im Supabase-SQL-Editor ausführen
- `ANLEITUNG.md`: Einrichtung, Benutzung, Sicherheit
